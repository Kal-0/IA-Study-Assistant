# ☁️ IsCoolGPT — Assistente Inteligente de Estudos em Cloud Computing

## 📘 Visão Geral

O **IsCoolGPT** é um **assistente educacional inteligente** desenvolvido para auxiliar estudantes em disciplinas de **Cloud Computing**.  
Ele utiliza **modelos de linguagem avançados (LLMs)**, integrados à **API do Gemini (Google Generative AI)**, para gerar explicações, resumos e respostas sobre temas técnicos.  

O projeto foi desenvolvido como parte do **Projeto Final Cloud 25.2**, demonstrando competências em:
- Desenvolvimento de APIs modernas com **FastAPI**  
- **Containerização com Docker**  
- **Integração e Entrega Contínuas (CI/CD)** com GitHub Actions  
- **Deploy automatizado na AWS** (ECR + ECS)  
- Aplicação de **boas práticas de DevOps e segurança**  

---

## 🧠 Objetivo

> Criar um assistente de estudos inteligente, modular e escalável, que possa responder dúvidas acadêmicas.
